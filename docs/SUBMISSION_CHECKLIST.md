# Submission checklist

- [ ] GitHub repository link (public, or shared with the tutor)
- [ ] Live Vercel link works (home page, login, a full booking)
- [ ] README: live link and repo link filled in (no placeholders left)
- [ ] README test accounts work on the LIVE site
- [ ] Spec, sitemap, flows, wireframes, style guide are in `docs/`
- [ ] Access-test screenshots saved in `docs/screenshots/`
- [ ] Bug explained: `docs/BUG_REPORT.md`
- [ ] No secret keys in the repo (search the repo for `sk_test`, `service_role`, `re_`)
- [ ] `.env.local` is NOT in the repo; `.env.example` has placeholders only
- [ ] Paystack is in TEST mode (keys start with sk_test_ and pk_test_)
- [ ] Commit history shows regular commits
- [ ] Demo rehearsed (5 minutes)
