# CleanPro: Style Guide (P04)

**Feel:** clean, calm, trustworthy, easy on a cheap phone.

| Item | Choice |
| :-- | :-- |
| Brand green | #027a48 (buttons, links, prices). Light tint #ecfdf3 for panels. |
| Text | Gray-900 on white. Secondary text gray-600 or darker (never lighter). |
| Status colours | Pending amber, Paid green, Assigned blue, In Progress indigo, Completed emerald, Cancelled gray. Every status also shows its **word**, never colour alone. |
| Errors / success | Red-800 on red-50 / green-900 on green-50, with role="alert" or role="status". |
| Font | System font stack (fast on slow connections, no downloads). |
| Buttons | Full-width or at least 44 px tall (comfortable thumb tap). |
| Forms | Visible label above every field, 48 px tall inputs, clear error text. |
| Icons | Lucide, decorative icons hidden from screen readers (aria-hidden). |
| Currency | Naira with thousands separator: N14,000 (shown with the naira sign). |
| Tone | Plain, friendly, short sentences. Real Benin City areas and landmarks. No lorem ipsum, no fake reviews. |
| Motion | None needed. |
