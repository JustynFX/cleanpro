# CleanPro

Home and office cleaning bookings for Benin City, Edo State.

## Setup
1. `npm install`
2. Create a Supabase project. Run `supabase/migrations/0001_schema.sql` in the SQL Editor.
3. `cp .env.example .env.local` and fill in your keys (Paystack TEST keys only).
4. `npm run dev` then open http://localhost:3000

Full README (users, test accounts, access-test screenshots) is completed in Phase 6.
